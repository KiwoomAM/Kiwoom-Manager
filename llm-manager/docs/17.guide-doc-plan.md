# guide-doc/ 작성 계획

sklearn 스타일 문서를 `packages/llm-request/guide-doc/`에 만드는 작업.
**이 문서는 작업 인수용** — 새 세션에서 이어서 진행할 때 이 파일부터 읽기.

---

## 목표

- sklearn 스타일(API Reference + User Guide + Examples)로 llm-request 문서화
- bus factor 낮추기 (상사·사내 팀원 개발자 인수 가능하게)
- 완성 후 한 번에 Claude Code skill 형식(`SKILL.md`)으로 변환

## 확정된 결정

| 항목 | 결정 |
|---|---|
| 형식 | Markdown only (Sphinx 안 씀) |
| 위치 | `packages/llm-request/guide-doc/` |
| 폴더 구조 | subfolder (`user-guide/`, `developer-guide/`) |
| 예제 코드 | 본문에 코드 블록 인라인 (별도 examples/ 디렉토리 X) |
| 독자 | 사내 팀원 + 상사 (외부 기여자 X) |
| Developer Guide | 자세히 — bus factor 목적 |
| 작업 순서 | 입구(`index.md`)부터 순서대로 |
| 진행 방식 | 섹션별 승인 (CLAUDE.md 6번 원칙) |
| Skill 변환 | 마지막에 한 번에 |
