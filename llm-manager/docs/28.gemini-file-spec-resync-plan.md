#### Task 3b: splitter 페이지 캡 (`max_pages`)

**Files:** `splitter.py`, `uploader.py`, `tests/_internal/file_processing/test_splitter.py`(없으면 생성)

**Interfaces (Produces):**
- `split_pdf(path, target_mb=50, max_pages=1000) -> list[str]` — 각 파트 ≤target_mb AND ≤max_pages
- `upload_pdf_parts(path, target_mb=50, max_pages=1000)` — `max_pages` 전달

- [ ] **Step 1: 실패 테스트** — `test_splitter.py` 에 fitz로 N페이지 PDF를 만들어 검증:
  - 1500p 소형 → `split_pdf(p, max_pages=1000)` 2파트, 각 `page_count ≤ 1000`
  - 2500p 소형 → 3파트, 각 ≤1000
  - 1000p 소형 → `[path]` (분할 안 함)
  - (회귀) 단일 페이지>50MB는 여전히 `PdfPageTooLargeError` — 기존 동작
- [ ] **Step 2: red 확인** — `max_pages` 인자 없음 → TypeError
- [ ] **Step 3: 구현** — `split_pdf` 시그니처에 `max_pages: int = 1000` 추가. 조기 반환을 `file_size ≤ target_bytes AND n_pages ≤ max_pages`로 좁히고(앞에서 `fitz`로 `n_pages` 1회 계산), 크기 분할/병합 결과(또는 크기 OK면 `[path]`)에 **페이지 캡 패스** 적용:
  ```python
  def _cap_pages(parts, src_path, max_pages, limit_bytes, created_temps):
      out: list[str] = []
      for p in parts:
          d = fitz.open(p); n = d.page_count; d.close()
          if n <= max_pages:
              out.append(p); continue
          k = math.ceil(n / max_pages)
          # n 페이지를 k등분 (각 등분 ≤max_pages)
          for j in range(k):
              group = list(range(j * n // k, (j + 1) * n // k))
              _split_group(p, group, limit_bytes, created_temps, out)  # 크기도 보장
          if p != src_path:  # 원본은 호출자 소유 — 건드리지 않음
              try: os.unlink(p)
              except OSError: pass
              if p in created_temps: created_temps.remove(p)
      return out
  ```
  `split_pdf` 본문에서 `result = _merge_adjacent(...)` 뒤(또는 크기 OK 분기에서 `result=[path]` 뒤)에 `result = _cap_pages(result, path, max_pages, limit_bytes, created_temps)` 호출. `import math` 추가.
- [ ] **Step 4:** `uploader.py` `upload_pdf_parts(path, target_mb=50, max_pages=1000)` → `split_pdf(path, target_mb, max_pages)` 전달
