> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Method 1 (data-mode `files=[FileInput(bytes)]`) 폐기. agent 가 file-manager 에 직접 등록 (`register_or_get` 헬퍼) 후 `file_path + 5 메타` 만 llm-request 에 전달. llm-request 는 lazy fetch — 실제 bytes 는 4·5단계 standby leader 만 가져온다.

**Tech Stack:** Python 3.x / FastAPI / Pydantic v2 / pytest / file-manager SDK / Redis (dedup standby) / MongoDB (cache)

**Spec:** [docs/21.method1-deprecation-lazy-fetch.md](./21.method1-deprecation-lazy-fetch.md)

**Pre-requisite:** Phase 1 + 2 ship 완료.

```python
    async def register_or_get(
        self,
        bytes_data: bytes,
        metadata: dict,
    ) -> dict:
        """check_cache → miss 면 upload_file → 6 필드 dict 반환.

        Phase 3 helper — agent 가 llm-request 호출 전에 file-manager 등록 책임을
        직접 가져갈 때 사용. 결과 dict 를 그대로 StoredFile(**result) 로 변환 가능.

        Args:
            bytes_data: 파일 바이트
            metadata: 5 필드 — file_name, file_size, file_mtime, mime_type, extension

        Returns:
            6 필드 dict — metadata + {"file_path": ...}
        """
        hash_meta = {
            "file_name": metadata["file_name"],
            "file_size": metadata["file_size"],
            "file_mtime": metadata["file_mtime"],
        }
        result = await self.check_cache(hash_meta)
        if result["hit"]:
            file_path = result["file_path"]
        else:
            file_path = await self.upload_file(bytes_data, metadata)
        return {**metadata, "file_path": file_path}
```

````markdown
### `register_or_get(bytes_data, metadata) → dict`

`check_cache` + `upload_file` 합성 헬퍼. 같은 파일이 file-manager 에 이미 있으면 그 file_path 반환, 없으면 upload 후 반환.

**입력:**
- `bytes_data: bytes` — 파일 바이트
- `metadata: dict` — 5 필드 (`file_name`, `file_size`, `file_mtime`, `mime_type`, `extension`)

**반환:** 6 필드 dict — `metadata` + `{"file_path": ...}`. 그대로 llm-request 의 `StoredFile(**result)` 로 변환 가능.

**사용 예시 (agent 측):**

```python
from file_manager import FileManagerHandler
from llm_request import StoredFile, llm_request_async

fm = FileManagerHandler()

# 파일 등록 (이미 있으면 skip, 없으면 upload)
with open("report.pdf", "rb") as f:
    bytes_data = f.read()
meta = fm.build_metadata("report.pdf")
sf_dict = await fm.register_or_get(bytes_data, meta)
del bytes_data  # bytes release — agent 메모리 회수

# llm-request 호출 (file_path 만 전송)
ref = StoredFile(**sf_dict)
response, _ = await llm_request_async(
    {"contents": "요약해줘", "model": "gemini-2.5-flash"},
    stored_files=[ref],
)
```

**Phase 3 동기:** llm-request 의 Method 1 (bytes 직접 전송) 폐기. agent 가 이 헬퍼로 file-manager 등록 책임을 가져가고 llm-request 에는 file_path 만 전달 → agent 메모리 + 네트워크 비용 절감.
````

```python
Phase 2 에선 여기서 file-manager fetch + 404 fallback 진행했으나,
Phase 3 에서 fetch 자체를 4·5단계 (resolver.py) 로 lazy 이전 — standby leader
만 fetch 하도록 dedup 메커니즘 활용.

설계: docs/21.method1-deprecation-lazy-fetch.md §5.4
"""

from __future__ import annotations

import logging

from file_manager import FileManagerHandler
from file_manager.exceptions import FMServiceError

from app.core.errors import FileResolveError
from app.logic.file_processing.validators import (
    validate_file_sizes,
    validate_mime_types,
)
from app.models.requests import FileInput, StoredFile

logger = logging.getLogger(__name__)


async def resolve_stored_files(refs: list[StoredFile]) -> list[FileInput]:
    """stored_files → placeholder FileInput list (data=b"") 변환.

    실제 fetch 는 안 함. validators 만 진입 즉시 적용 (fail-fast).
    실제 bytes 는 resolver.py 의 _process_inline / _upload_and_cache_file
    에서 lazy 하게 fetch.
    """
    placeholders = [
        FileInput(
            file_name=ref.file_name,
            file_size=ref.file_size,
            file_mtime=ref.file_mtime,
            mime_type=ref.mime_type,
            extension=ref.extension,
            data=b"",                        # placeholder — lazy fetch 전제
            file_path=ref.file_path,
            resolved_via="primary",
        )
        for ref in refs
    ]

    # fail-fast: file-manager 호출 전 mime/size 검증
    validate_mime_types(placeholders)
    validate_file_sizes(placeholders)

    return placeholders


async def fetch_with_fallback(fm: FileManagerHandler, fi: FileInput) -> bytes:
    """file_path 로 bytes fetch. 404 시 check_cache → 새 path 재시도 → fallback.

    호출자: resolver.py 의 _process_inline / _upload_and_cache_file.
    miss 시 FileResolveError raise. resolved_via 'fallback' 으로 갱신.
    """
    try:
        data, _ = await fm.get_file(fi.file_path)
        return data
    except FMServiceError as e:
        if e.status_code != 404:
            raise

        cache = await fm.check_cache({
            "file_name": fi.file_name,
            "file_size": fi.file_size,
            "file_mtime": fi.file_mtime,
        })
        if not cache["hit"]:
            raise FileResolveError(
                f"file_path '{fi.file_path}' not found, "
                f"check_cache miss for file_name={fi.file_name}"
            ) from e

        new_path = cache["file_path"]
        logger.warning(
            "[Phase3] stale file_path: input=%s, resolved=%s, file_name=%s",
            fi.file_path, new_path, fi.file_name,
        )
        fi.file_path = new_path
        fi.resolved_via = "fallback"
        data, _ = await fm.get_file(new_path)
        return data
```
